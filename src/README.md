# Source code

Lab này **không có code**. Toàn bộ bài làm là file Markdown và hình ảnh trong `report/`.

- File bắt đầu chạy: không có
- Cách chạy: không cần chạy
- Input: trải nghiệm thật của bạn, kết quả phỏng vấn/survey, tài liệu research
- Output: `report/individual/MSSV_HoTen.md`, `report/team/group_report.md`, `TEAM.md`, file phụ trong `report/assets/`
- File học viên được sửa: `report/individual/MSSV_HoTen.md` (sau khi đổi tên), `report/team/group_report.md`, `TEAM.md`, thêm file vào `report/assets/`

Nếu nhóm muốn làm thử một prototype nhỏ (không bắt buộc, không tính điểm), có thể đặt ở đây kèm hướng dẫn chạy.
