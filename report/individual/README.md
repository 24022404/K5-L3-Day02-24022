# Báo cáo cá nhân

Đổi tên file `MSSV_HoTen.md` theo MSSV và họ tên không dấu:

```text
report/individual/MSSV_HoTen.md
```

Ví dụ: `report/individual/20241234_NguyenVanAn.md`.

File này chứa phần **cá nhân** của bài: CP1 (scan), CP2 (top 3 Problem Cards), CP7 (reflection) và nhật ký tham gia nhóm.
